
# Plant Disease Detector (Deep Learning & AI — Week 2)

An end-to-end Computer Vision web application that uses a fine-tuned MobileNetV2 Deep Neural Network to diagnose plant leaf diseases from uploaded photographs and display real-time confidence scores[cite: 38].

---

## 📌 Features

- **Transfer Learning Backbone:** MobileNetV2 pre-trained on ImageNet and fine-tuned for botanical disease classification[cite: 38].
- **Flask Web Application:** Lightweight backend for file upload handling and model inference[cite: 38].
- **Interactive UI:** Real-time leaf image preview, instant prediction output, and healthy vs. diseased status indicators[cite: 38].
